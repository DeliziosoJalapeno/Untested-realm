#### UI Improvements ####
- **Pre-game "VS" splash** — when a game opens, a full-screen intro shows both **avatars** and player names (**Player 1 vs Player 2**), then fades; click/tap to skip.
- **Floating mana** — every time a source provides mana, a **+n ◆** rises over it for a moment: your sites at the start of your turn (Towers +2), passive sources like **Älvalinne Dryads** / **Finwife**, a freshly-played site, and tap-for-mana minions like **Field Laborers**.
- **Deck pickers** now list **your decks first** (A–Z), then the built-in default decks (A–Z).
- **Deck confirm / Start view** now has a **card-detail panel** on the right — hover (or tap) any card in the list to read it.
- **Scrollbars** now match the site's dark colour scheme.
- **Mulligan panel overhaul** — a much bigger, taller dialog; your opening hand is shown in **two balanced rows**; the rest of the board dims behind it (the card-detail panel stays lit); and **"Keep hand" now asks for confirmation** (mulligan is still one click). A crowded hand (7+) uses slightly smaller cards so both rows still fit.
- **Bigger card popups** on desktop — the "opponent revealed…" notice and the choose-a-card / Browse / first-site prompts show their cards larger.
